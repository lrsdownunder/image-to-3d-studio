# Decision log

Record the decision, why, trade-offs, evidence and what would make us revisit it.

## D001 — Self-hosted generation

Status: existing project constraint, confirmed in AGENTS.md.
Use the self-hosted GPU backend for 3D generation. Do not replace it with a proprietary 3D API.
The site/backend contract and signed status updates must remain consistent.

## D002 — Majoto 3D branding

Status: chosen by the owner; implementation requires acceptance testing (#1).
Use warm ivory #F7F5F0, charcoal #222222, violet #7455F6 and restrained lime #DDF58A.
Use a light creative-studio homepage and a dark model viewing area.
Preserve working generation, authentication and downloads.

## D003 — Evidence before Done

Status: adopted for project tracking.
Implementation goes to Needs testing. Move to Done only after acceptance checks are recorded.
Compare geometry separately from colour/texture when assessing model quality.
